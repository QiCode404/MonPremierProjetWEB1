# PromoENI – Trombinoscope de Promotion

Projet réalisé dans le cadre de la formation **Développeur Web & Web Mobile** à l’ENI École Informatique.

Ce site permet d’afficher les apprenants d’une promotion sous forme de **liste** ou de **cartes**, de consulter leurs informations détaillées, et de visualiser leur localisation sur une **carte interactive**.

---

## Fonctionnalités principales

### ✔️ Page d’accueil
- Affichage des apprenants :
  - **Liste (tableau)** avec scroll vertical
  - **Cartes (grid)** avec photos et bouton “Détail”
- Choix du mode d’affichage mémorisé via **localStorage**
- Accès rapide aux autres pages du site

### ✔️ Page Informations
- Dates de la formation
- Nombre d’apprenants
- Description du projet
- Liens utiles (DevMozilla, Bootstrap, W3Schools, ENI)

### ✔️ Page Préférences
- Choix du thème : **Clair / Sombre**
- Choix du format d’affichage : **Liste / Cartes**
- Sauvegarde automatique via **localStorage**


### ✔️ Modal Détail
- Affichage des informations complètes d’un apprenant
- Photo, nom, prénom, ville, anecdote
- Ouverture via Bootstrap Modal

---

## 🧩 Technologies utilisées

- **HTML5**
- **CSS3**
- **JavaScript**
- **Bootstrap 5**
- **Leaflet.js**
- **localStorage**
- **JSON (promo.json)**
